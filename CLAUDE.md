# Инструкции для сессий реализации

- Язык общения и документации разработки (ТЗ, ADR, отчёты, планы) — русский. Код, идентификаторы и комментарии в коде — английский.
- Интерфейс программы (GUI, сообщения CLI), пользовательская и публичная техническая документация — английский (ТЗ v1.7 §14.8, ADR-0034). Ядро не формирует текст для пользователя: `am::Error` с `message_id` (ADR-0032).
- Источник требований — `docs/tz/drafts/TZ_catalog_3D_2D_draft_v1.8.md` (v1.7 + §19: этапы P0–P3, формат ZIP MF-01…MF-12). Решения — отчёты `docs/reports/04_TZ_v1.7_vs_prepared.md` и `05_TZ_v1.8_format_vs_prepared.md`, приняты целиком.
- Формат ZIP-ассета — ТЗ §19.4, ADR-0035, ADR-0036 (уточнения R-01…R-09: `docs/tz/R01-R09_approved_handoff.md`, отчёт 06) и ADR-0037 (журнал решений v0.11, 108 принципов: `docs/tz/RC1_decisions_after_e2472e9_v0.11.md`, отчёт 07); рабочая формализация `docs/specifications/container_manifest_v1.md`, нормативная схема `schemas/manifest-1.0.schema.json`. **Формат 1.0 опубликован 2026-11-14** (ADR-0039): схема, валидатор V1–V4 и golden ZIP (`tests/fixtures/golden/`, T-013); механизм точных чисел — ADR-0038. Опубликованные схема 1.0 и golden ZIP 1.0 **не меняются**: исправления — только новыми случаями или новой `minor` по `docs/specifications/versioning.md`. Проверка схемы — ctest `schema_check`, корпуса — `golden_zip`/`golden_regen_check`, SQL-контрактов — `sql_check`.
- Числовые нормативы не назначаются до измерений (ТЗ §14.9.13): `docs/architecture/nfr_measurement_plan.md`. Статусы требований — `docs/plan/acceptance_matrix.md`; версии форматов — `docs/specifications/versioning.md`.
- Архитектурные решения — `docs/decisions/ADR_log.md`, см. таблицу статусов в начале. Отклонение от ADR допускается только через новую ADR.
- Исходные материалы владельца **не изменять**:
  - `docs/tz/description.txt`;
  - `docs/tz/drafts/TZ_*.md` — новые версии ТЗ создаются только новыми файлами;
  - материалы владельца в `docs/tz/`: `AUDIT_REPORT.md`, `asset-format-*.md`, `R01-R09_*.md`, `RC1_*.md`, `*.zip`;
  - `tools/inventory/inventory_3d_resources.py`;
  - `data/inventory/3d_Models_inventory_*.zip`.
- Коллекция `D:\!!!_USER_FOLDERS\Downloads\Telegram Desktop\3d_Models\` — **только чтение**.
  - **Уточнение владельца (2026-11-23):** исходный набор ассетов перенесён на внешний диск, пополняется и уже не соответствует инвентаризации 2026-11-05 (`data/inventory/`) и выводам отчёта 02. Прежний путь может быть неполным или неактуальным. Если набор понадобится — сначала уточнить у владельца текущее расположение; старую инвентаризацию считать историческим снимком, новую делать новым файлом. Режим «только чтение» действует и для нового расположения.
  - Синтетические тестовые данные — в `tests/fixtures/`.
  - Реальные файлы коллекции используются только через реестр `tests/real/registry.json`: чтение на месте, без копирования (ADR-0029).
- Изменения за пределами каталога проекта запрещены без явного разрешения владельца. Сборка направляет TMP и кэши в `.cache/` (см. `tools/build_min.cmd`, `CMakePresets.json`).
- Перед реализацией модуля сверить и дополнить `docs/research/libraries.md` (ТЗ 3.5.1).
- Уровни (ADR-0024): `foundation` → `contracts` → `domain` → `jobs` / `storage` / `processing` → `services` / `automation` / `plugin_runtime` / `ai` → `application`.
  - Код лежит в `src/<level>/` и `include/am/<level>/`.
  - Зависимости — только по матрице ADR-0024; проверяются тестом `arch_check`.
  - `am_foundation` не имеет внешних зависимостей.
  - Действующие ZIP меняет только `storage::AssetRepository` (ADR-0025).
- Ошибки — `am::Result<T>`, без исключений через границы модулей и C ABI плагинов.
- Сборка и тесты — `tools\build_min.cmd` (MSVC 14.44, Ninja, GoogleTest через FetchContent в `.cache/`).
- После изменения статуса сценария или требования обновить `docs/plan/coverage_matrix.md` и/или `docs/plan/acceptance_matrix.md`; в тестах — `RecordProperty("req", "K-n|NFR-14.x.y|SC-n")`.
- **Реализация (пауза снята владельцем 2026-11-10).** Исполнитель — Codex (VS Code, та же папка, правила — `AGENTS.md`); управляющий и проектировщик — Claude Code.
