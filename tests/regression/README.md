# tests/regression — регрессионный набор (ТЗ §12.9.8, §13.4.10)

Каждый исправленный воспроизводимый дефект получает здесь тест. Обязательные случаи по ТЗ §12.9.8:
- одиночный STL;
- несколько масштабов;
- многотомные и вложенные архивы;
- AppleDouble по сигнатуре;
- нетривиальные имена и исходные байты имён;
- повреждённые архивы;
- 3MF;
- несколько архивов одного ресурса;
- проверка без импорта;
- повторный поиск по SHA-256.

Корпус T-034 (`tests/fixtures/import/`, ctest `import_corpus.*`) проверяет
одиночный STL, разные масштабы в двух ZIP, вложенные ZIP с тремя решениями,
тома по именам и пропуск номера, AppleDouble по сигнатуре, длинные/Unicode/
не-UTF-8/опасные имена, CRC-ошибку в strict/partial, настоящий и ложный 3MF,
готовый ассет и повторный scan с сохранёнными SHA-256. Байты генерируются,
ожидания хранятся отдельно; source/temp-инварианты действуют для каждого
случая. На Linux запись в библиотеку не проверяется по политике ФС.

Остаются: настоящие многотомные RAR/7z (есть только неподтверждённые имена),
проверка по внешнему изображению/файлу без импорта и отдельный поиск по SHA-256
в каталоге (M4). Повторный import scan --library --hash — проверка подсказок
и skip-identical, а не реализация команды поиска или сравнения геометрии.
