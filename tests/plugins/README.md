# tests/plugins — тестовые плагины (ADR-0026, ТЗ §12.9.6)

Появляются вместе с плагин-хостом (веха M5P):
- `ok` — корректный плагин;
- `old_api` — устаревший `requires_api`;
- `missing_dep` — отсутствующая зависимость;
- `init_fail` — отказ `init`;
- `process_error` — ошибка обработки;
- `long_task` — долгая отменяемая задача;
- `unknown_ext` — сохранение неизвестных полей `ext`;
- `crash_worker` — авария во внешнем процессе.
