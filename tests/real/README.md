# tests/real — реальные минимальные и комплексные наборы (ADR-0029, ТЗ §13.4.1, §13.4.9)

Здесь хранится **только реестр** `registry.json`, без самих данных. Для каждой записи указываются:
- путь в контрольной коллекции (только чтение) или во внешнем хранилище;
- размер и SHA-256;
- назначение и номер сценария §13.2.

Тесты читают файлы на месте. Если файл недоступен или его SHA-256 не совпадает, тест пропускается (`GTEST_SKIP`). Такие тесты имеют метку ctest `real`. Закрытые данные не публикуются и в репозиторий не копируются.

> **Уточнение владельца (2026-11-23):** исходный набор ассетов перенесён на внешний диск, пополняется и уже не соответствует инвентаризации 2026-11-05 (`data/inventory/`) и выводам отчёта 02. Прежний путь может быть неполным или неактуальным. Если набор понадобится — сначала уточнить у владельца текущее расположение; старую инвентаризацию считать историческим снимком, новую делать новым файлом. Режим «только чтение» действует и для нового расположения. Корень `collection` в `registry.json` указывает на прежний путь; записей пока нет. При добавлении первых записей корень обновить по ответу владельца.
