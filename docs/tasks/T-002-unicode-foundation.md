# T-002. Unicode в foundation: NFC и simple case folding, коллизии путей по ADR-0035 п. 8

**Статус:** done (принята 2026-11-10) · **Веха:** M1, шаг 0 · **Основание:** ADR-0035 п. 8, ADR-0024 (`am_foundation` без внешних зависимостей), приёмка T-001 (замечание о бюджете длины)

## Цель

Два пути одного ZIP, совпадающие после NFC и Unicode simple case folding, должны считаться коллизией (ADR-0035 п. 8). Сейчас `ZipPathMapper` сравнивает только с ASCII-свёрткой: `Café.stl` (NFC) и `café.stl` (NFD) получают разные пути и ломаются на NTFS и macOS. Нужна собственная, детерминированная, не зависящая от ОС и локали реализация NFC и simple case folding по **зафиксированной версии Unicode** — без ICU и других внешних библиотек, потому что `am_foundation` не имеет внешних зависимостей.

## Решения управляющего (не пересматривать в задаче)

- **Версия Unicode — 17.0.0.** Если на `https://www.unicode.org/Public/17.0.0/ucd/` нужных файлов нет, остановись и опиши это в отчёте; версию не подменяй.
- **Данные UCD хранятся в репозитории** (`third_party/unicode/17.0.0/`) вместе с `SHA256SUMS` и лицензией Unicode. Так генерация таблиц воспроизводима офлайн, а тест соответствия всегда выполним.
- **Таблицы генерируются** Python-скриптом (только стандартная библиотека) в `src/foundation/unicode_tables.inc`. Сгенерированный файл коммитится. Тест проверяет, что повторная генерация даёт тот же файл байт в байт.
- **Ключ коллизии** `path_collision_key(s) = NFC(simple_casefold(NFC(s)))`. Внешняя NFC нужна, потому что свёртка регистра может нарушить нормализацию.
- **Сам путь в ZIP не нормализуется** (ADR-0035 п. 8: «исходная форма имени не нормализуется»). Нормализация используется только для сравнения занятости.
- **Simple case folding** — строки CaseFolding.txt со статусом `C` и `S`. Статусы `F` (полная свёртка, `ß` → `ss`) и `T` (турецкая) **не используются**.

## Критерии приёмки

1. **Соответствие UAX #15 по NormalizationTest.txt:** для каждой строки всех частей файла `nfc(c1) == c2`, `nfc(c2) == c2`, `nfc(c3) == c2`, `nfc(c4) == c4`, `nfc(c5) == c4`. Плюс инвариантность: каждая кодовая точка (кроме суррогатов), которая не встречается в части 1, не меняется под `nfc`. Тест читает файл из `AM_UNICODE_DATA_DIR`. Ноль расхождений.
2. **Case folding:** для каждой строки `C`/`S` из CaseFolding.txt `simple_casefold(src) == dst`. Точечные проверки: `ẞ` (U+1E9E) → `ß`; `ß` не меняется; `K` (U+212A, знак Кельвина) → `k`; `İ` (U+0130) не меняется (у неё только `F`/`T`); `Σ` → `σ`; `ς` → `σ`.
3. **UTF-8:** `is_valid_utf8` отклоняет overlong (`C0 AF`), суррогаты (`ED A0 80`), > U+10FFFF (`F4 90 80 80`), обрывы; `nfc` на них → `Errc::invalid_argument`.
4. **Коллизии путей:**
   - `Café.stl` (NFC) и `café.stl` (NFD) — коллизия, второй получает суффикс `~<8hex>`;
   - `ΣΊΣΥΦΟΣ.stl` и `σίσυφος.stl` — коллизия;
   - `STRASSE.stl` и `straße.stl` — **не** коллизия (simple folding);
   - NFD-имя без коллизий сохраняется в `zip_path` **без нормализации**.
5. **Бюджет длины:** корень 45 байт + расширение длиной 170 байт + коллизия → результат ≤ 200 байт, без переполнения; тест на тот же случай в ветке `path_too_long`.
6. **Воспроизводимость:** `unicode_tables_check` проходит; `SHA256SUMS` сверяется генератором.
7. `arch_check` проходит: у `am_foundation` нет внешних зависимостей.
8. `tools\build_min.cmd`: все тесты проходят (63 + новые), новых предупреждений нет. Тесты помечены `RecordProperty("req", "ADR-0035")`.
9. Отчёт по `AGENTS.md` п. 5. Дополнительно: размер `unicode_tables.inc` и время теста соответствия.

### Отклонения от первоначального объёма и решения управляющего

В ходе работы выявлено, что для произвольного корня исходный API не может одновременно сохранить корень и обеспечить лимит 200 байт. Управляющий в ответе в чате от 2026-11-10 уточнил контракт и явно разрешил расширение T-002:

- `kCollisionTagBytes = 9` и `kMaxRootBytes = kMaxZipPathBytes - kCollisionTagBytes - 1 = 190` — public static constexpr.
- `static Result<ZipPathMapper> create(std::string root)` отклоняет пустой корень и корень длиннее 190 байт **после добавления завершающего `/`** с `Errc::invalid_argument`.
- Конструктор private: создать маппер в обход проверки нельзя. Заголовок `include/am/foundation/paths.hpp` изменён для этого API и констант.
- Область T-002 расширена на `src/application/cli/main.cpp`: CLI переведён на фабрику, при ошибке печатает английскую диагностику и возвращает код 1. Все вызовы в тестах также переведены на фабрику; добавлены проверки 190/191 байт.
- При проверенном корне резерв под суффикс и хотя бы один байт основы гарантирован. Если целый UTF-8-символ не помещается в однобайтовую основу, используется `_`, без разрыва UTF-8.

Решение реализовано. Остальные изменения находятся в первоначальном списке разрешённых файлов; ADR, спецификации, схемы, ТЗ и материалы владельца не менялись.

В исходном `CompositionExclusions.txt:32` есть завершающий пробел. Полный `git diff --check` отмечает его при добавлении файла; он сохранён по требованию хранить исходные байты UCD без изменений.
