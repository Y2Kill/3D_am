# Количественные целевые показатели (закрывает ТЗ 14.2 рабочими значениями)

Эталонная машина: Windows 10/11 x64, 8 ядер, 32 ГБ RAM, NVMe SSD, GPU с OpenGL 4.x. Значения — цели для бенчмарков `bench/`, их можно уточнять.

| Область | Показатель | Цель |
|---|---|---|
| Объём библиотеки | ассетов | 100 000 (проектный предел без деградации UI), коллекция-эталон ≈ 650 |
| | файлов внутри ассетов | 3 000 000 строк в `files` |
| | размер одного ассета | до 50 ГиБ, отдельный файл до 16 ГиБ (ZIP64) |
| Импорт | пропускная способность | ≥ 80 % последовательной скорости чтения источника (с SHA-256 и Deflate); STL сжимается с уровнем 6 при ≥ 300 МБ/с на поток |
| | накладные расходы на мелкий ассет (< 10 МБ) | ≤ 300 мс |
| Индекс | полное перестроение | ≤ 2 мин на 10 000 ассетов (чтение только манифестов) |
| | быстрая синхронизация при открытии | ≤ 3 с на 100 000 ассетов (stat + сравнение с индексом) |
| Поиск | быстрый поиск по мере ввода | ≤ 100 мс p95 на 100 000 ассетов |
| | «есть ли у нас этот архив?» (lookup по sha256) | ≤ 50 мс после хеширования входа |
| | pHash-поиск похожих | ≤ 200 мс на 500 000 изображений |
| GUI | прокрутка карточек | 60 FPS, миниатюры подгружаются асинхронно |
| | открытие ассета (метаданные + дерево) | ≤ 200 мс |
| | первое изображение STL 1 млн треугольников | ≤ 1,5 с от двойного клика (чтение из ZIP + upload в GPU) |
| | максимальная модель без LOD | 10 млн треугольников интерактивно (≥ 30 FPS) |
| Память | процесс GUI в простое | ≤ 400 МБ |
| | кэш геометрии | 2 ГиБ по умолчанию (настраивается) |
| Надёжность | потеря данных при kill -9 / отключении питания в любой момент | 0 корректных ассетов потеряно (тест «kill во время commit», 1 000 итераций) |
| Сеть | запросов в сеть в базовой поставке | 0 |
