# Исходные материалы ТЗ

- `description.txt` — первичное описание идеи (исходное сырьё).
- `drafts/` — черновики ТЗ v0.1–v1.8. **Актуальный: `drafts/TZ_catalog_3D_2D_draft_v1.8.md`.**
  - v1.2 — v1.1 + восстановленные потери (генерируется `tools/tz_audit/make_v1_2.py`);
  - v1.3–v1.5 — редакции владельца (§11, §12, §13);
  - v1.6 — v1.5 + принятые рекомендации отчёта 03: подтверждены П-1…П-6, заполнен §17, рабочие ответы на вопросы 29/32/33/35/38 (генерируется `tools/tz_audit/make_v1_6.py`).
  - v1.7 — версия владельца на базе v1.6: нефункциональные требования §14.1–14.9, испытания 112–136, вопросы 41–50; потерь нет. Сверка и решения — отчёт `docs/reports/04_TZ_v1.7_vs_prepared.md` (принят целиком).
  - v1.8 — версия владельца: v1.7 + §19 (этапы P0–P3, контрольные точки P0.1–P0.8, формат ZIP MF-01…MF-12); §1–17 без изменений. Сверка и решения — отчёт `docs/reports/05_TZ_v1.8_format_vs_prepared.md` (принят целиком), ADR-0035.
- Материалы владельца к v1.8 (не изменять):
  - `AUDIT_REPORT.md` — отчёт самосверки версий v0.1–v1.8;
  - `asset-format-consensus-v0.2.md` — рабочая консолидация формата (= §19.4);
  - `asset-format-working-spec-v0.1.md`, `asset_format_working_v0.1_bundle.zip` — **устаревший** пакет до MF-01…MF-12, не эталон (§19.6.2);
  - `catalog_TZ_v1.8_consistency_audit_2026-11-06.zip` — пакет сверки (все версии, скрипт аудита).

Файлы владельца (`description.txt`, черновики, материалы к v1.8) не изменять. Новые версии создаются только как новые файлы.
