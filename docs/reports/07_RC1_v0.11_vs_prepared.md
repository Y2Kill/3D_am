**Замечания без вопроса владельцу** (исполнение; войдут в план):
- **O-02 п. 8.** Тип `value` для стандартных полей V2 может проверить через `if target.field = X then value: <схема поля X>` (9 полей + 5 полей источника). Для `custom` — V3. Это выбор реализации, не вопрос.
- **O-02 / O-14.** `source.url` в схеме — свободная строка. Для единообразия применить `$defs.url`, как требует O-14 п. 2 для `license.url`.
- **O-02 п. 3.** Шаблон `$defs.date` пропускает `2026-13-45`; календарную допустимость проверяет V3.
- **X-01 п. 4.** Внутренний детектор `include/am/storage/archive/volume_detect.hpp:33` нумерует пропуски с 1 (`missing_indices // 1-based`). Это внутреннее представление, а не формат, но при записи `volumes[].index` нужно преобразование: индекс — позиция тома в наборе, а не номер из имени. Код — после паузы.
- **O-11 п. 8.** `sdk/include/am/am_plugin.h:102` содержит устаревший комментарий «stored under manifest `ext["x.<plugin-id>"]`». По ADR-0035/O-11 ключ — `extensions.<ExtensionID>`, где ExtensionID = PluginID, без префикса `x.`. Исправить при S6/M1; ID возможностей (`metadata.extract`) — отдельная сущность, как и требует п. 8.
- **O-11 п. 2.** Длинный ExtensionID (96 байт) оставляет под путь вложения 200 − 12 − 96 − 1 = 91 байт. Это допустимо, но длину пути V3 должен проверять отдельно (как и сказано в п. 2).
- **O-14 п. 5.** Грамматика `generation.tool` не задана (пример: `am.preview.mesh`). Пока — непустая строка с точным сравнением; поддеталь записать как OPEN.
- **O-16.** `zip_size` — размер файла на ФС, а не значение из манифеста, поэтому выйти за int64 он не может. Перевод в TEXT утверждён для единообразия; возражений нет. `state.sql: edit_session_files.size` — размеры файлов рабочей папки на ФС, к индексу не относится: O-16 его не затрагивает.
